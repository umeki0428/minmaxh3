# 絵コンテフォーマット

絵コンテを書くときの雛形。項目名と順序はこのとおりに固定する。話の中身は入れず、書き方だけを残したもの。

絵コンテ工程は AI が全部作る。人間はフィードバックを返すだけで、構成もカット割りも画も書かない。

---

## 見出し

```markdown
# 絵コンテ｜<作品名>
```

冒頭に、原作が何か（原作なしなら「オリジナル」）と、映像としての基本仕様を1〜2行で書く。

```markdown
原作は<原作の形式・読み順>。
映像では同じ出来事を **時系列<N>カット・尺<N>秒（<fps> / <アスペクト比>）** に展開する。
```

## 全体の流れ

カット名・カット番号・尺を1枚で見せる。最初にリズムを確定させ、以降のカット記述はここからずれないようにする。

````markdown
```
<動き1> → <動き2> → <動き3> → ... → <動きN>
 CUT01     CUT02     CUT03           CUT0N
  <秒>      <秒>      <秒>            <秒>
```
````

原作がある場合は対応表を置く。1コマを複数カットに割る、逆に複数コマを1カットにまとめる、といった変換をここで明示する。

```markdown
| 原作 | 映像 |
|---|---|
| <コマの位置・大きさ> | CUT <番号> <役割> + CUT <番号> <役割> |
```

原作と変えた点（省略されている動作を足す、順序を入れ替える、など）は、理由まで書く。原作にない画を勝手に足したのか、映像として必要だから足したのかが後で判別できるようにする。

## カット

カットごとに次の9項目を、この順で全部書く。値が無い項目は省略せず「なし」と書く。

```markdown
## CUT <番号>　<カット名>

- 尺：<秒>秒（<開始 hh:mm:ss> – <終了 hh:mm:ss>）
- 原作：<対応するコマ／「原作にない」＋足した理由>
- 画：`cuts/cut-<番号>-<英語スラッグ>.png`
- サイズ：<画面サイズと構図。誰をどこに置くか>
- カメラ：<固定／寄り／引き／パン／ティルト／シェイク。いつ動くか>
- 内容：<この尺の中で起きること。1〜2文>
- セリフ：<話者「セリフ」／なし。言語も指定する>
- SE：<効果音。タイミングが要るものは「掛け声と同時」等まで>
- 演出：<このカットが担う役割。前後とどう繋がるか>
```

各項目の決め方：

| 項目 | 書くこと | 注意 |
| --- | --- | --- |
| 尺 | 秒数と、通しのタイムコード | 全カットの合計＝全体尺。ここが合わないと編集で破綻する |
| 原作 | 対応するコマ。無いなら足した理由 | 原作からの逸脱を隠さない |
| 画 | `cuts/` 内のファイル名 | 番号と英語スラッグ。連番とカット番号を一致させる |
| サイズ | 引き／寄り／アップ、被写体の配置 | 隣り合うカットでサイズを変え、同サイズの連続を避ける |
| カメラ | 動きの種類と、動き出すタイミング | 動かさないなら「固定」と明記する |
| 内容 | 起きる出来事だけ | 感情の説明ではなく、画に写るものを書く |
| セリフ | 話者と原文 | 意味を取らせない言語なら、そう書く |
| SE | 音と、画に対する位置 | ピークとなる音は1カットに集約する |
| 演出 | このカットが要る理由 | ここが書けないカットは削る候補 |

## つなぎ

カット間の接続を表にする。カット単体では決まらない情報なので、必ず別立てにする。

```markdown
| 接続 | 方法 |
|---|---|
| <前> → <後> | <カット／音だけ連続／アクション繋ぎ／同一空間で尺を伸ばす など> |
```

## キャラと画面の指定

全カットで共通する見た目を1か所にまとめる。カットごとに書くと必ず食い違うので、ここだけを正とする。

```markdown
- <キャラ名>：<髪・服・体格・動きの質>
- <キャラ名>：<同上。複数いるなら、手前に大きく映る個体の扱いも>
- 場所：<場所、地面、光>
- 色：<絵コンテの色（通常モノクロ）と、本番で主役にする色>
```

## 音の設計

短尺なら、音は全体で1本の線として設計する。

```markdown
1. 導入の高さとテンポ
2. どのカットからテンポを上げるか
3. ピークはどのカットか（原則1つ）
4. どこで落とすか
```

BGM を入れるかどうか、入れるならピーク前後でどう扱うかまで書く。

## ファイル構成

```
<作品ディレクトリ>/
  絵コンテ.md          このフォーマットで書いた本体
  index.html          閲覧用（画とテキストを並べたもの）
  cuts/
    cut-01-<スラッグ>.png
    cut-02-<スラッグ>.png
    ...
```
