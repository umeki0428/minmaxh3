# 絵コンテ｜女戦士 × ゴブリン戦

原作は日本の漫画1ページ（右上始まり、右→左 / 上→下）。  
映像では同じ出来事を **時系列7カット・尺10秒（24fps / 16:9）** に展開する。

## 全体の流れ

```
囲まれる → 決意 → 踏み込む → 旋回 → 蹴る → 倒す → 次へ備える
 CUT01     CUT02    CUT03     CUT04   CUT05   CUT06    CUT07
  2.0s      0.8s     0.4s      0.8s    1.5s    1.5s     3.0s
```

漫画4コマとの対応：

| 原作 | 映像 |
|---|---|
| 1コマ目（右上・大縦） | CUT 01 導入 + CUT 02 顔 |
| 2コマ目（左上・小横） | CUT 03 踏み込み |
| 3コマ目（中央・横長） | CUT 04 予備動作 + CUT 05 打撃 |
| 4コマ目（下段・横長） | CUT 06 ダウン + CUT 07 余韻 |

漫画は「着弾」と「結果」を大きく描き、予備動作を省略している。  
動画では CUT 04 を1拍足して、キックが成立するようにする。

画は `cuts/` を参照。HTML版は `index.html`。

## CUT 01　導入

- 尺：2.0秒（00:00:00 – 00:02:00）
- 原作：1コマ目
- 画：`cuts/cut-01-establishing.png`
- サイズ：やや引き。戦士を中央、手前左右のゴブリンで囲む
- カメラ：ロー気味固定 → ゆっくりプッシュイン
- 内容：女戦士が複数のゴブリンに包囲される。低い構え。まだ打たない
- セリフ：ゴブリン側のファンタジー言語（威嚇。意味は不明でよい）
- SE：低いうなり、葉擦れ
- 演出：人数と危機を最初に見せ、次の顔アップへつなぐ

## CUT 02　顔

- 尺：0.8秒（00:02:00 – 00:02:20）
- 原作：1コマ目から切り出し
- 画：`cuts/cut-02-face.png`
- サイズ：バストアップ〜顔アップ
- カメラ：わずかに寄る
- 内容：決意の表情。視線は正面の敵
- セリフ：なし（短い吐息）
- SE：環境音を落とす
- 演出：「囲まれた側」から「攻める側」へ切り替える

## CUT 03　踏み込み

- 尺：0.4秒（00:02:20 – 00:03:05）
- 原作：2コマ目
- 画：`cuts/cut-03-footstep.png`
- サイズ：足元の大アップ。ローアングル
- カメラ：接地の瞬間に小さくシェイク
- 内容：軸足が地面を踏む。砂が跳ねる
- セリフ：なし
- SE：**タンッ**
- 演出：漫画の小コマと同じく、きっかけだけを切ってテンポを上げる

## CUT 04　予備動作

- 尺：0.8秒（00:03:05 – 00:04:00）
- 原作：3コマ目の直前（漫画では省略）
- 画：`cuts/cut-04-windup.png`

- カメラ：回転に合わせた短いパン

- SE：衣擦れ、風切り
- 演出：映像用のつなぎ。ここがないとキックが突然すぎる

## CUT 05　打撃（このページの頂点）

- 尺：1.5秒（00:04:00 – 00:05:12）
- 原作：3コマ目
- 画：`cuts/cut-05-kick.png`

- 内容：回し蹴りがゴブリンに入る

- 演出：一番大きく、一番長く。背景に残敵を残し、戦いが未完だと示す

## CUT 07　余韻

## つなぎ

| 接続 | 方法 |
|---|---|
| 01 → 02 | カット。音だけ連続 |
| 02 → 03 | カット。顔から足元へ飛ばし、動作の開始を強調 |
| 03 → 04 → 05 | アクションはほぼ連続。カット割りは細かく、動きは止めない |
| 05 → 06 | ヒットから落下へ直結 |
| 06 → 07 | 同じ空間の引き。時間を少し伸ばす |

## キャラと画面の指定

- 女戦士：短い明るい髪、白いチュニック（暗い縁取り）、茶色のベルト、暗いショートパンツ。動きは軽く、低い重心
- ゴブリン：筋骨、尖った耳、長い鼻。複数で囲む。倒れる1体は手前で大きく
- 場所：森の空き地。土、草、木漏れ日
- 色：絵コンテはモノクロ。本番は原作に合わせ、戦士の白を主役色にする

## 音の設計（短尺）

1. 導入は低く、遅い
2. CUT 03 からテンポを上げる
3. CUT 05 が唯一のピーク（掛け声＋打撃）
4. CUT 07 で急に静かにする

BGMを入れるなら CUT 05 まで抑え、打撃のあとに余韻のドローンだけ残す。
